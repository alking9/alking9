## 🔥 Featured Work

### [SortCentric](https://github.com/alking9/sortcentric)  
A sorting algorithm visualizer built from scratch with React and TypeScript.  
Animations for Bubble Sort, Merge Sort, and Quick Sort — clean layout, step-by-step highlighting, and a complexity chart built in.  
[Live Demo](https://sortcentric.vercel.app)
